# Autonomous Data Warehouse Engineering Platform

A collaborative AI Data Engineering Crew built using CrewAI Flows to profile, analyze, schema-design, and transform raw department datasets into an analytics-ready warehouse.

## Project Structure

```
Autonomous_Data_Engineering_Platform/
├── .agents/            # Workspace local rules
├── agents/             # Agent definitions via AgentFactory
├── tasks/              # Task definitions via TaskFactory
├── tools/              # Custom OOP class-based tools
├── data/               # Input datasets (CRM, Product, Sales, Support)
├── reports/            # Output documents generated by the crew
├── main.py             # Entrypoint and Flow definition
└── README.md
```

## Setup & Running Instructions

### 1. Requirements
Ensure Python 3.12 is installed. Using pyenv:
```bash
pyenv shell 3.12.11
```

### 2. Environment Installation
Create a virtual environment and install dependencies:
```bash
python -m venv venv
source venv/bin/activate
pip install crewai pandas duckdb chromadb
```

### 3. Model Configuration
This system is configured to run locally via Ollama with the model `nemotron-3-ultra:cloud`. Ensure Ollama is running:
```bash
ollama serve
ollama pull nemotron-3-ultra:cloud
```

### 4. Running the Flow
Kick off the automated flow pipeline:
```bash
python main.py
```

### 5. Outputs
All output analysis deliverables are generated inside the `reports/` folder:
- **`profiling_report.json`**: Structural profiling metadata.
- **`quality_report.md`**: Integrity score and details of anomalies.
- **`schema_design.md`**: Warehouse star schema key relationships.
- **`transformations.sql`**: DuckDB SQL scripts to load Fact and Dimension tables.
- **`kpi_report.md`**: Extracted KPIs and insights.
- **`executive_summary.md`**: Final executive recommendations report.

### 6. LangSmith Tracing & Observability (Optional)
To monitor agent operations, LLM prompts, latency, and costs in real-time inside the LangSmith interface:
1. Copy your LangSmith API key from [smith.langchain.com](https://smith.langchain.com).
2. Set the following keys in your `.env` file:
   ```env
   LANGCHAIN_TRACING_V2=true
   LANGCHAIN_API_KEY=your_actual_langsmith_api_key_here
   LANGCHAIN_PROJECT=ADEP-Data-Warehouse-Crew
   ```
3. Run the pipeline (`python main.py` or the web dashboard). The traces will automatically appear in your LangSmith project space.
